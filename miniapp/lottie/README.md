# Папка для настоящих анимаций Telegram (необязательно)

Mini App **полностью работает без этой папки**: все эмодзи нарисованы вручную
в SVG и анимированы через CSS.

Если положить сюда файлы с такими именами, приложение подхватит их автоматически
и покажет вместо своих SVG:

```
empty.json       — поле пустое
faible.json      — слабый пароль
moyen.json       — средний
fort.json        — сильный
tres_fort.json   — очень сильный
```

Формат — **Lottie JSON** (это тот же формат, что и телеграмовские `.tgs`,
только не сжатый gzip).

Получить их можно так:

```bash
node bot/fetch-emoji.mjs AnimatedEmojies
```

или, если у тебя есть конкретные premium-эмодзи:

```bash
node bot/fetch-emoji.mjs --custom 5368324170671202286 5368324170671202287
```

Как узнать `custom_emoji_id`: отправь боту сообщение с нужным премиум-эмодзи —
бот прочитает `message.entities[].custom_emoji_id` и покажет его тебе.
