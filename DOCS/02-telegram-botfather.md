# Шаг за шагом: создаём бота и подключаем Mini App

> Это самая «ручная» часть — её нельзя сделать кодом, только руками в Telegram.
> Займёт 10 минут. Ничего сложного.

---

## Шаг 1. Создать бота у @BotFather

1. Открой Telegram, найди **@BotFather** (у него синяя галочка).
2. Нажми `/start`, затем отправь:
   ```
   /newbot
   ```
3. BotFather спросит **имя** бота — это то, что видят люди. Например:
   ```
   Vérificateur de mot de passe
   ```
4. Затем спросит **username** — должен заканчиваться на `bot` и быть уникальным. Например:
   ```
   kirill_mdp_checker_bot
   ```
5. В ответ придёт **токен** вида:
   ```
   <10 цифр>:<35 букв и цифр>   ← так выглядит настоящий токен
   ```

> ⚠️ **Токен — это пароль от бота.** Кто его знает, тот управляет ботом.
> Никогда не выкладывай его на GitHub, не показывай в отчёте, не вставляй в скриншоты.
> Если случайно засветил — `/revoke` у BotFather, и получишь новый.

---

## Шаг 2. Положить токен в `.env`

В папке проекта:

```bash
cp bot/.env.example bot/.env
```

Открой `bot/.env` и впиши токен:

```
BOT_TOKEN=<10 цифр>:<35 букв и цифр>   ← так выглядит настоящий токен
MINIAPP_URL=
```

`MINIAPP_URL` заполним на шаге 4, когда выложим Mini App в интернет.

Файл `bot/.env` уже добавлен в `.gitignore` — в git он не попадёт.

---

## Шаг 3. Проверить, что бот живой

```bash
node bot/bot.js
```

Должно появиться сообщение, что бот запущен. Найди своего бота в Telegram по username,
нажми `/start` — он ответит. Кнопки Mini App пока не будет, это нормально.

Останови бота через `Ctrl+C`.

---

## Шаг 4. Выложить Mini App в интернет

Telegram умеет открывать **только `https://`**-адреса. Локальный `http://localhost` не подойдёт.
Как это сделать — подробно в **[03-deploiement.md](03-deploiement.md)**.

Самый быстрый вариант — GitHub Pages, и ты получишь адрес вида:

```
https://ТВОЙ_ЛОГИН.github.io/password-checker/miniapp/
```

Впиши его в `bot/.env`:

```
MINIAPP_URL=https://ТВОЙ_ЛОГИН.github.io/password-checker/miniapp/
```

## Шаг 5. Прикрепить Mini App к боту (кнопка меню)

Это делает синюю кнопку слева от поля ввода в чате с ботом.

1. Напиши @BotFather: `/mybots`
2. Выбери своего бота → **Bot Settings** → **Menu Button** → **Configure menu button**
3. Отправь URL твоей Mini App (тот же, что в `.env`)
4. Отправь текст кнопки, например:
   ```
   🔐 Vérifier
   ```

Теперь в чате с ботом внизу слева появится кнопка, открывающая приложение.

## Шаг 6. (Рекомендую) Сделать прямую ссылку на Mini App

Так у приложения будет собственная ссылка вида `t.me/твой_бот/checker` — её удобно
дать преподавателю и вставить в отчёт.

1. @BotFather → `/newapp`
2. Выбери бота
3. **Title** — `Vérificateur de mot de passe`
4. **Description** — `Vérifiez la force de votre mot de passe en temps réel.`
5. **Photo** — картинка **640×360** (можно нарисовать что угодно, обязательна)
6. **GIF** — можно пропустить командой `/empty`
7. **Web App URL** — твой https-адрес
8. **Short name** — например `checker`

Готово: `https://t.me/kirill_mdp_checker_bot/checker`

## Шаг 7. (Красиво) Прописать команды бота

@BotFather → `/setcommands` → выбери бота → отправь одним сообщением:

```
aide - Comment ça marche
regles - Les 4 niveaux de sécurité
generer - Générer un mot de passe très fort
```

Теперь при вводе `/` Telegram будет подсказывать команды.

## Про «премиум эмодзи» — важно и честно

Ты хотел анимированные премиум-эмодзи. Вот как обстоят дела на самом деле:

| Где | Можно ли анимированные эмодзи | Пояснение |
|---|---|---|
| **Внутри Mini App** | ✅ **Да, без ограничений** | Это обычная веб-страница. Мы рисуем свои анимированные SVG-эмодзи, а при желании подгружаем настоящие Telegram-анимации (формат `.tgs` = сжатый Lottie). Premium не нужен. |
| **В сообщениях бота: стикеры** | ✅ Да | Бот свободно шлёт анимированные стикеры (`sendSticker`). |
| **В сообщениях бота: custom emoji (премиум-эмодзи внутри текста)** | ⚠️ Только с платным юзернеймом | Telegram разрешает ботам вставлять `<tg-emoji emoji-id="…">` в текст, **только если у бота есть username, купленный на Fragment**. Для учебного проекта это не нужно. |

**Поэтому вся красота живёт внутри Mini App** — и это как раз то, что ты хотел.
Наши эмодзи нарисованы вручную в SVG и анимированы CSS: они работают всегда, у всех,
без интернета и без Premium.

Если захочешь подгрузить **настоящие** телеграмовские анимации:

```bash
node bot/fetch-emoji.mjs AnimatedEmojies
```

Скрипт скачает `.tgs`, распакует в Lottie JSON и положит в `miniapp/lottie/`.
Mini App подхватит их автоматически, а если файлов нет — покажет свои SVG.
